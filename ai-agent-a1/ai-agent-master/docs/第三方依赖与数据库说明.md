# A1 多模态设备检修知识检索与作业系统第三方依赖与数据库说明

## 1. 文档目的

本文档说明系统运行需要的第三方软件、数据库、模型服务和初始化脚本，明确哪些内容应放入提交包，哪些内容只需在文档中说明安装方式。

## 2. 是否需要把数据库放进可执行文件

不建议把 PostgreSQL、Node.js、Java JDK 等第三方软件安装包直接放进 `executables` 目录。

推荐原因：

- 数据库和运行时环境属于第三方基础软件，不是本项目自身可执行文件。
- 不同操作系统和 CPU 架构需要不同安装包，比赛最终环境是 LoongArch + 银河麒麟，Windows 安装包不能直接使用。
- 安装包体积大，容易导致提交包过大。
- 第三方软件可能涉及单独授权、版本和平台兼容问题。

本项目提交包中应保留：

- 后端可执行 jar。
- 前端构建产物 dist。
- 数据库建表和种子数据 SQL。
- `.env.example` 环境变量模板。
- 数据库安装和配置说明文档。

## 3. 必需依赖

| 依赖 | 用途 | 是否必须 | 是否放进可执行文件 |
| --- | --- | --- | --- |
| Java 21 | 运行 Spring Boot 后端 jar | 必须 | 不放，文档说明安装 |
| Node.js / npm | 本地开发或启动 Vite 前端 | 开发/演示需要 | 不放，文档说明安装 |
| DashScope/Qwen API Key | AI 问答、工具智能体、视觉分析 | AI 功能必须 | 不放，只配置环境变量 |
| PostgreSQL | 业务数据持久化 | 推荐启用 | 不放，文档说明安装 |
| pgvector | 向量知识库检索 | 可选 | 不放，文档说明安装 |

## 4. 数据库说明

### 4.1 推荐数据库

本地开发已验证使用 PostgreSQL。当前项目配置支持：

```text
DB_URL=jdbc:postgresql://localhost:5432/ai_agent
DB_USERNAME=postgres
DB_PASSWORD=postgres
APP_JDBC_PERSISTENCE_ENABLED=true
```

如果没有启动 PostgreSQL，系统会使用内存演示数据，仍可完成核心演示流程。

### 4.2 数据库名称

推荐数据库名：

```text
ai_agent
```

创建数据库示例：

```powershell
& "C:\Program Files\PostgreSQL\18\bin\createdb.exe" -U postgres ai_agent
```

如果数据库已经存在，无需重复创建。

### 4.3 表结构与种子数据

项目已经内置数据库脚本：

```text
src/main/resources/sql/maintenance_schema.sql
src/main/resources/sql/maintenance_seed.sql
```

启用 `APP_JDBC_PERSISTENCE_ENABLED=true` 后，后端启动时会自动执行建表和种子数据初始化。

如需手动执行，可使用：

```powershell
cd C:\Users\123\Desktop\Coding\agent\ai-agent-a1\ai-agent-master
& "C:\Program Files\PostgreSQL\18\bin\psql.exe" -U postgres -d ai_agent -f .\src\main\resources\sql\maintenance_schema.sql
& "C:\Program Files\PostgreSQL\18\bin\psql.exe" -U postgres -d ai_agent -f .\src\main\resources\sql\maintenance_seed.sql
```

## 5. PgVector 说明

PgVector 是可选能力，用于真实向量检索。

默认建议：

```text
APP_PGVECTOR_ENABLED=false
```

原因：

- 比赛演示时稳定性优先。
- 未安装 pgvector 时开启该能力可能导致启动失败。
- 系统已经支持本地 Markdown、故障案例和已审核经验检索，足够完成基础演示。

如果比赛虚拟机支持安装 pgvector，可再设置：

```text
APP_PGVECTOR_ENABLED=true
```

并在数据库中启用扩展：

```sql
CREATE EXTENSION IF NOT EXISTS vector;
```

## 6. Windows 本地环境准备

### 6.1 Java

检查：

```powershell
java -version
javac -version
echo $env:JAVA_HOME
```

要求 Java 21。

### 6.2 Node.js / npm

检查：

```powershell
node -v
npm -v
```

建议 Node.js 18 及以上。

### 6.3 PostgreSQL

检查：

```powershell
& "C:\Program Files\PostgreSQL\18\bin\psql.exe" --version
& "C:\Program Files\PostgreSQL\18\bin\psql.exe" -U postgres -l
```

如果希望在任意 PowerShell 目录直接使用 `psql`，可把 PostgreSQL 的 `bin` 目录加入系统 Path。

## 7. 银河麒麟 LoongArch 环境准备

最终比赛环境应在 LoongArch + 银河麒麟高级服务器操作系统中验证。

需要准备：

- LoongArch 可用的 Java 21。
- LoongArch 可用的 Node.js/npm。
- LoongArch 可用的 PostgreSQL。
- 可选安装 pgvector。
- 配置 DashScope API Key。

详细部署步骤见：

```text
docs/银河麒麟LoongArch部署说明.md
```

## 8. 提交包中应包含的数据库相关文件

| 文件 | 是否包含 | 说明 |
| --- | --- | --- |
| `src/main/resources/sql/maintenance_schema.sql` | 是 | 建表脚本 |
| `src/main/resources/sql/maintenance_seed.sql` | 是 | 演示种子数据 |
| `.env.example` | 是 | 数据库和模型环境变量模板 |
| `docs/第三方依赖与数据库说明.md` | 是 | 安装和配置说明 |
| PostgreSQL 安装包 | 否 | 第三方软件，不建议放入提交包 |
| pgvector 安装包 | 否 | 第三方扩展，不建议放入提交包 |
| 真实 `.env` | 否 | 可能包含密钥和数据库密码 |

## 9. 可执行文件目录推荐内容

`executables` 目录建议只放项目自身产物：

```text
executables/
├─ backend/
│  └─ ai-agent-0.0.1-SNAPSHOT.jar
└─ frontend-dist/
   ├─ index.html
   └─ assets/
```

数据库、Java、Node.js、Nginx 等环境依赖写入文档即可。
