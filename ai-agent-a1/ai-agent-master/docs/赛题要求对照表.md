# 软件杯 A1 赛题要求对照表

本文档用于本地开发收尾和答辩自检，说明当前 `Li` 分支已实现的功能与赛题要求之间的对应关系。

## 1. 硬性运行环境要求

| 赛题要求 | 当前项目对应内容 | 验证方式 |
| --- | --- | --- |
| B/S 架构 | 后端 Spring Boot，前端 Vue 3 + Vite | 后端 `http://localhost:8123/api`，前端 `http://127.0.0.1:5173/love-app` |
| PC Web 或 App 可视化界面 | `/love-app` 设备检修中台，`/files` 文件中心 | 浏览器访问页面并完成演示流程 |
| 自主指令系统 LoongArch + 银河麒麟 V11/V10 | 已补充部署说明 | 在大赛虚拟机执行 `uname -m`，需要显示 `loongarch64` |
| 云端或本地大模型服务 | DashScope/Qwen OpenAI 兼容模式 | `.env` 配置 `DASHSCOPE_API_KEY` 和 `DASHSCOPE_CHAT_MODEL` |

说明：本地 Windows 环境用于功能开发和构建验证，最终提交前仍需在比赛提供的 LoongArch / 银河麒麟虚拟机完成真实运行验证。

## 2. 基本功能要求

| 赛题功能 | 已实现内容 | 页面 | 后端接口 | 关键文件 |
| --- | --- | --- | --- | --- |
| 多模态知识检索 | 支持文本问题、本地 Markdown、故障案例、已审核经验统一检索；可选 PgVector 向量检索 | 知识库、AI 知识问答 | `POST /api/maintenance/knowledge/search`，`GET /api/ai/app/chat/sse` | `LocalKnowledgeService.java`，`VectorKnowledgeService.java`，`MaintenanceService.java` |
| 故障图片输入 | 支持图片描述、图片 URL 调 Qwen-VL、本地上传图片直接调 Qwen-VL，失败时自动回退本地特征分析 | 视觉分析 | `POST /api/maintenance/image/analyze`，`POST /api/maintenance/vision/analyze`，`POST /api/maintenance/vision/upload` | `VisionAnalysisService.java`，`LoveApp.vue` |
| 设备型号/设备类型输入 | 设备台账和诊断表单支持设备编号、类型、位置、传感器项 | 设备台账、多模态诊断 | `GET/POST /api/maintenance/devices`，`POST /api/maintenance/diagnose` | `DeviceAsset.java`，`InspectionRequest.java` |
| 标准化作业指引 | 诊断后自动生成作业单，包含步骤、备件工具、验收标准 | 检修作业单 | `POST /api/maintenance/diagnose`，`POST /api/maintenance/tasks` | `MaintenanceTask.java`，`MaintenanceService.java` |
| 合规校验提醒 | 作业建议包含停机、断电、泄压、挂牌上锁、PPE 等安全要求 | 多模态诊断、作业单 | `POST /api/maintenance/diagnose` | `actionsForRisk`，`buildTaskArchiveMarkdown` |
| 个性化流程推送 | 根据风险等级生成不同优先级和检修动作 | 多模态诊断 | `POST /api/maintenance/diagnose` | `riskLevel`，`createTask` |
| 知识沉淀与更新 | 一线经验提交、专家审核，通过后进入案例库并生成 Markdown/PDF | 知识库、文件中心 | `POST /api/maintenance/knowledge/contributions`，`POST /api/maintenance/knowledge/contributions/{id}/review` | `KnowledgeContribution.java`，`MaintenanceService.java` |
| 手动标注与修正模型输出 | 报告中心支持专家修正风险、证据、原因、措施，并保存记录 | 报告中心 | `POST /api/maintenance/reports/corrections`，`GET /api/maintenance/reports/corrections` | `ReportCorrectionRecord.java`，`MaintenanceService.java` |
| 作业状态闭环 | 支持待派工、处理中、待验收、专家复核、驳回整改、已归档 | 作业流转、检修作业单 | `POST /api/maintenance/tasks/{taskId}/flow`，`GET /api/maintenance/tasks/flow` | `TaskFlowEvent.java`，`validateTransition` |
| 演示稳定性 | 支持一键重置演示数据，避免现场数据混乱 | 顶部操作区 | `POST /api/maintenance/demo/reset` | `MaintenanceJdbcRepository.java`，`LoveApp.vue` |

## 3. 数据与持久化

| 数据类型 | 当前实现 |
| --- | --- |
| 设备台账 | 内存演示兜底，可选 PostgreSQL 持久化 |
| 故障案例 | 内置案例 + 专家审核通过的经验自动沉淀 |
| 检修任务 | 自动生成 / 手动创建，支持 PostgreSQL 持久化 |
| 作业流转记录 | 每次状态变化写入流转日志 |
| 诊断报告 | Markdown/PDF 归档，文件中心可查看 |
| 知识审核记录 | 提交、审核、驳回均可保留 |
| AI 修正记录 | 报告中心独立保存专家修正记录 |
| RAG 知识库 | 默认本地 Markdown + 案例检索，可选 PgVector |

## 4. 非功能性要求

| 非功能要求 | 当前项目对应内容 |
| --- | --- |
| 界面合理、美观 | 检修工作台采用侧边导航、卡片式数据区、表单和状态机，适合桌面演示 |
| 文档完整规范 | `README.md`、`docs/完整项目运行说明.md`、`docs/银河麒麟LoongArch部署说明.md`、本文档 |
| 交互便捷 | 前端支持刷新、重置、自动生成作业单、归档下载、知识审核和 AI 问答 |
| 易用性与稳定性 | 默认内存演示兜底，数据库和 PgVector 均为开关配置；新增 `scripts/check-local.ps1` 做本地验收 |

## 5. 推荐答辩演示路径

1. 打开 `/love-app`，展示态势看板和一键重置演示数据。
2. 进入设备台账，新建设备，说明设备类型、位置、传感器项可沉淀。
3. 进入视觉分析，演示图片描述、上传图片分析或图片 URL 调 Qwen-VL。
4. 点击“生成诊断与作业单”，展示多模态诊断结果。
5. 进入检修作业单，演示待派工、处理中、待验收、专家复核、驳回整改、已归档。
6. 进入知识库，提交一条现场经验，专家审核通过后进入案例库。
7. 进入报告中心，导出报告并演示专家修正 AI 输出。
8. 打开 AI 知识问答，提问故障处置方案并展示引用知识来源。
9. 最后说明 PostgreSQL 持久化和 PgVector 向量检索开关，以及 LoongArch / 银河麒麟最终部署验证计划。

## 6. 当前剩余风险

- LoongArch / 银河麒麟虚拟机仍需最终真实验证，这是赛题硬性要求。
- Qwen-VL 对图片 URL 的访问依赖公网可达性；本项目已支持本地上传图片直接调用 Qwen-VL，并保留本地规则兜底，避免现场完全不可演示。
- PgVector 需要数据库安装 pgvector 扩展；未安装时建议保持 `APP_PGVECTOR_ENABLED=false`，优先保证系统稳定运行。
