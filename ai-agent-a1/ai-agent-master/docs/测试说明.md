## 6. 功能测试用例

| 编号 | 测试项 | 操作步骤 | 预期结果 |
| --- | --- | --- | --- |
| T01 | 后端健康检查 | 启动后端，访问 `/api/health` | 返回健康状态 |
| T02 | 前端访问 | 启动前端，访问 `/love-app` | 检修工作台页面正常显示 |
| T03 | AI 检修问答 | 在 AI 知识问答输入设备故障问题 | 返回结构化检修建议，Markdown 正常渲染 |
| T04 | 新建设备 | 在设备台账中填写设备名称、类型、位置、风险等级 | 设备列表新增该设备 |
| T05 | 多模态诊断 | 输入设备、温度、振动、电流、故障描述和图片特征 | 返回风险等级、证据、可能原因、建议和相似案例 |
| T06 | 生成作业单 | 基于诊断结果生成作业单 | 作业单列表出现新任务，包含步骤、备件和验收标准 |
| T07 | 作业流转 | 在作业单或作业流转页点击下一步状态 | 状态按规则变化，并新增流转记录 |
| T08 | 图片 URL 分析 | 输入图片 URL 和问题后执行视觉分析 | 返回可见缺陷、风险等级、原因和建议 |
| T09 | 图片上传分析 | 上传本地图片并执行分析 | 优先返回 Qwen-VL 视觉分析结果；模型不可用时返回本地视觉特征分析结果 |
| T10 | 知识提交 | 提交一线检修经验 | 知识贡献列表出现待审核记录 |
| T11 | 知识审核 | 专家审核通过知识贡献 | 记录状态变为已通过，并沉淀为案例/归档文件 |
| T12 | 知识检索 | 使用故障关键词检索知识库 | 返回 Markdown、案例或已审核经验命中结果 |
| T13 | 报告归档 | 生成或归档诊断报告 | 报告中心/文件中心可查看相关文件 |
| T14 | AI 修正 | 在报告中心填写专家修正内容并保存 | 修正记录列表出现新增记录 |
| T15 | 演示重置 | 点击重置演示数据或调用 `/demo/reset` | 演示种子数据恢复 |
| T16 | PostgreSQL 持久化 | 开启 `APP_JDBC_PERSISTENCE_ENABLED=true` 后新建设备并重启 | 重启后新增设备仍存在 |

## 9. 已知风险与处理

| 风险 | 影响 | 处理方式 |
| --- | --- | --- |
| GitHub 网络不稳定 | 推送或拉取代码失败 | 网络稳定后重试，或使用代理/HTTP 配置 |
| DashScope API Key 未配置 | AI 问答不可用 | 使用 `.env` 或环境变量配置 `DASHSCOPE_API_KEY` |
| Qwen-VL 无法访问图片 URL | 图片 URL 分析失败 | 使用本地图片上传分析兜底 |
| PostgreSQL 未启动 | 持久化不可用 | 默认内存演示模式仍可运行 |
| pgvector 未安装 | 向量检索不可用 | 保持 `APP_PGVECTOR_ENABLED=false`，使用本地知识检索 |
| 未在 LoongArch 验证 | 可能不满足赛题硬性要求 | 最终提交前必须在比赛虚拟机运行并截图留证 |
