## 2. 源代码

### 2.1 必交源码目录

| 路径 | 内容 |
| --- | --- |
| `ai-agent-a1/ai-agent-master/src` | Spring Boot 后端源码、业务服务、RAG、工具、配置、SQL |
| `ai-agent-a1/ai-agent-master/ai-agent-frontend/src` | Vue 3 前端源码 |
| `ai-agent-a1/ai-agent-master/ai-agent-frontend/package.json` | 前端依赖和构建脚本 |
| `ai-agent-a1/ai-agent-master/pom.xml` | 后端 Maven 依赖和构建配置 |
| `ai-agent-a1/ai-agent-master/mvnw`、`mvnw.cmd`、`.mvn` | Maven Wrapper |
| `ai-agent-a1/ai-agent-master/scripts` | 本地启动和检查脚本 |
| `ai-agent-a1/ai-agent-master/.env.example` | 环境变量模板 |
| `image-backend-a1` | 图片后端候选融合模块，作为扩展源码保留 |
| `README.md` | 仓库总说明 |

### 2.2 不建议提交的本地文件

| 文件/目录 | 原因 |
| --- | --- |
| `.git` | 不是比赛材料必须内容，除非平台要求完整 Git 仓库 |
| `node_modules` | 体积大，可通过 `npm install` 恢复 |
| `.env` | 可能包含真实 API Key 或数据库密码 |
| `tmp` | 本地生成文件，可现场重新生成 |
| `*.log` | 本地运行日志，无需提交 |
| `.idea`、`.vscode` | 个人 IDE 配置 |

## 3. 可执行/可部署文件

### 3.1 后端 jar

当前后端可执行文件：

```text
ai-agent-a1/ai-agent-master/target/ai-agent-0.0.1-SNAPSHOT.jar
```

重新生成命令：

```powershell
cd C:\Users\123\Desktop\Coding\agent\ai-agent-a1\ai-agent-master
.\mvnw.cmd -DskipTests package
```

运行示例：

```powershell
$env:DASHSCOPE_API_KEY="你的DashScope密钥"
java -jar target\ai-agent-0.0.1-SNAPSHOT.jar
```

### 3.2 前端 dist

当前前端构建产物：

```text
ai-agent-a1/ai-agent-master/ai-agent-frontend/dist
```

重新生成命令：

```powershell
cd C:\Users\123\Desktop\Coding\agent\ai-agent-a1\ai-agent-master\ai-agent-frontend
npm install
npm run build
```

部署方式：

- 开发演示：使用 `scripts/start-frontend.ps1` 启动 Vite。
- 正式部署：将 `dist` 放入 Nginx、静态文件服务器或比赛平台指定 Web 服务目录。

## 6. 推荐打包命令

以下命令会在 `C:\Users\123\Desktop\Coding` 下生成提交目录和 zip。执行前建议先运行 `scripts/check-local.ps1`。

```powershell
$repo = "C:\Users\123\Desktop\Coding\agent"
$project = "$repo\ai-agent-a1\ai-agent-master"
$out = "C:\Users\123\Desktop\Coding\A1-设备检修知识检索与作业系统-Li"

New-Item -ItemType Directory -Force "$out\source-code" | Out-Null
New-Item -ItemType Directory -Force "$out\executables\backend" | Out-Null
New-Item -ItemType Directory -Force "$out\executables\frontend-dist" | Out-Null
New-Item -ItemType Directory -Force "$out\documents" | Out-Null

robocopy $repo "$out\source-code" /E /XD .git node_modules target dist tmp .idea .vscode /XF .env *.log
Copy-Item "$project\target\ai-agent-0.0.1-SNAPSHOT.jar" "$out\executables\backend\" -Force
Copy-Item "$project\ai-agent-frontend\dist\*" "$out\executables\frontend-dist\" -Recurse -Force
Copy-Item "$repo\README.md" "$out\documents\README-仓库总说明.md" -Force
Copy-Item "$project\README.md" "$out\documents\README-主项目说明.md" -Force
Copy-Item "$project\docs\*.md" "$out\documents\" -Force

Compress-Archive -Path "$out\*" -DestinationPath "$out.zip" -Force
```
