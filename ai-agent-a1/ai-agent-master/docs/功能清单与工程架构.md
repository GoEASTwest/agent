# 功能清单与工程架构

## 当前工程模块

### 1. AI 检修问答

- Spring AI + DashScope 对话模型
- SSE 流式输出
- 文件型会话记忆
- RAG advisor 接入本地检修知识库
- 工具调用能力：网页检索、文件操作、PDF 生成、资源下载

### 2. 检修业务中台

- 设备台账
- 风险态势看板
- 故障案例知识库
- 多模态诊断输入
- 风险评分和证据链
- 相似案例匹配
- 自动生成检修作业单
- 图片描述特征分析
- 作业单状态流转
- 服务端诊断报告生成
- 报告导出

### 3. 多模态扩展位

- 图片可见特征录入
- 故障图像案例标签
- 可接入 `image-backend` 的图片上传、审核、相似检索
- 可接入 Qwen-VL、InternVL 或 CLIP 向量检索

## 后端包结构

```text
com.hp.aiagent
├── agent              # ReAct / ToolCall 智能体
├── app                # 检修问答应用
├── chatmemory         # 会话记忆
├── controller         # AI 对话接口
├── maintenance        # 设备检修业务域
│   ├── controller     # 业务 REST API
│   ├── model          # 台账、案例、诊断、作业单模型
│   └── service        # 风险评分、案例匹配、作业单生成
├── rag                # 知识库加载、切分、检索增强
└── tools              # 文件、搜索、PDF、下载等工具
```

## 推荐继续堆的功能

1. 用户和角色权限：巡检员、检修员、专家、管理员。
2. 图片上传：复用 `image-backend` 的上传、标签、审核、空间管理。
3. 知识库管理：文档上传、切分、向量化、召回测试。
4. 作业流转：待派工、处理中、待验收、已归档。
5. 报告中心：诊断报告、作业指导书、复盘报告。
6. 专家审核：AI 结论可被专家确认、修正、沉淀为案例。
7. 模型评测：准备标准案例集，统计诊断命中率和召回准确率。

## 答辩展示路径

1. 进入态势看板，说明系统不是单点问答，而是检修业务中台。
2. 查看设备台账，选择高风险电机或泵。
3. 打开案例知识库，说明知识沉淀来源。
4. 在多模态诊断页输入温度、振动、电流和图片特征。
5. 系统生成风险等级、证据链、可能原因和作业建议。
6. 查看自动生成的作业单，展示步骤、备件和验收标准。
7. 导出报告，形成检修闭环。
