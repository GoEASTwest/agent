# A1 多模态设备检修知识检索与作业系统

## 项目定位

本项目面向中国软件杯 A1 题目，目标是构建设备检修知识检索、故障诊断、图片特征分析、作业单生成、报告归档的一体化系统。

系统不是单一聊天机器人，而是围绕检修业务闭环构建：

```text
设备台账 -> 多模态输入 -> 知识库召回 -> 风险诊断 -> 相似案例 -> 作业单 -> 报告归档 -> 案例沉淀
```

## 当前功能

- 设备态势看板
- 设备台账
- 故障案例知识库
- 文本、参数、图片特征联合诊断
- 图片描述特征分析
- 风险评分和证据链
- 相似案例匹配
- 自动生成检修作业单
- 作业单状态流转
- 诊断报告生成和导出
- RAG 知识文档清单
- AI 检修问答
- 后端离线时的前端演示兜底

## 运行环境

前端：

- Node.js 18+
- npm

后端：

- Java 21
- Maven
- DashScope API Key
- PostgreSQL + PgVector，后续持久化使用

## 核心接口

| 接口 | 方法 | 功能 |
| --- | --- | --- |
| `/api/maintenance/dashboard` | GET | 态势看板 |
| `/api/maintenance/devices` | GET | 设备台账 |
| `/api/maintenance/cases` | GET | 故障案例 |
| `/api/maintenance/tasks` | GET | 作业单列表 |
| `/api/maintenance/knowledge` | GET | 知识库文档 |
| `/api/maintenance/diagnose` | POST | 多模态诊断 |
| `/api/maintenance/image/analyze` | POST | 图片特征分析 |
| `/api/maintenance/tasks/{taskId}/status` | POST | 作业单状态更新 |
| `/api/maintenance/reports` | POST | 诊断报告生成 |
| `/api/ai/app/chat/sse` | GET | AI 检修问答 |

## 答辩演示流程

1. 打开首页，说明系统覆盖检修业务闭环。
2. 进入设备检修中台，展示态势看板。
3. 查看设备台账，选择严重风险的电机。
4. 打开案例知识库，说明故障知识沉淀方式。
5. 打开图片分析，输入“焦痕、变色、绝缘破损”等描述，获得图片特征和相似案例。
6. 打开多模态诊断，输入温度、振动、电流和图片特征，生成风险等级和证据链。
7. 查看自动生成的检修作业单，并演示状态流转。
8. 导出诊断报告，完成闭环。
