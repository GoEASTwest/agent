# A1 多模态设备检修知识检索与作业系统

## 项目定位

本项目面向中国软件杯 A1 题目，目标是构建设备检修知识检索、故障诊断、图片特征分析、作业单生成、报告归档的一体化系统。

系统不是单一聊天机器人，而是围绕检修业务闭环构建：

```text
设备台账 -> 多模态输入 -> 知识库召回 -> 风险诊断 -> 相似案例 -> 作业单 -> 报告归档 -> 案例沉淀
```

## 当前功能

- 设备态势看板
- 设备台账
- 故障案例知识库
- 文本、参数、图片特征联合诊断
- 图片描述特征分析
- 风险评分和证据链
- 相似案例匹配
- 自动生成检修作业单
- 作业单状态流转
- 诊断报告生成和导出
- RAG 知识文档清单
- AI 检修问答
- 后端离线时的前端演示兜底

## 运行环境

前端：

- Node.js 18+
- npm

后端：

- Java 21
- Maven Wrapper，已随项目提供
- DashScope API Key
- PostgreSQL + PgVector，后续持久化使用，默认演示模式不强制依赖

当前机器如果只有 Java 8，后端无法启动，需要安装 Java 21 并配置 `JAVA_HOME`。

## 启动前端

```powershell
cd "ai-agent-a1\ai-agent-master"
.\scripts\start-frontend.ps1
```

访问：

```text
http://127.0.0.1:5173
```

## 启动后端

```powershell
cd "ai-agent-a1\ai-agent-master"
$env:DASHSCOPE_API_KEY="your-dashscope-api-key"
.\scripts\start-backend.ps1
```

也可以复制 `.env.example` 为 `.env` 后填写密钥，启动脚本会自动读取。

后端地址：

```text
http://localhost:8123/api
```

## 核心接口

| 接口 | 方法 | 功能 |

| `/api/ai/app/chat/sse` | GET | AI 检修问答 |

## 数据库

表结构：

```text
src/main/resources/sql/maintenance_schema.sql
```

种子数据：

```text
src/main/resources/sql/maintenance_seed.sql
```

当前默认演示模式仍使用内存数据，便于快速启动；当 `APP_JDBC_PERSISTENCE_ENABLED=true` 时，`MaintenanceService` 会切换到 JDBC Repository 持久化。

默认配置已关闭 PostgreSQL + PgVector 和 MCP 自动连接。当前已经支持可选 JDBC 业务持久化，开启后设备、案例、作业单、流转记录、报告、知识提交和审核记录会写入 PostgreSQL。

开启方式：

```powershell
$env:DB_URL="jdbc:postgresql://localhost:5432/ai_agent"
$env:DB_USERNAME="postgres"
$env:DB_PASSWORD="postgres"
$env:APP_JDBC_PERSISTENCE_ENABLED="true"
.\scripts\start-backend.ps1
```

也可以在 `.env` 中配置：

```text
DB_URL=jdbc:postgresql://localhost:5432/ai_agent
DB_USERNAME=postgres
DB_PASSWORD=postgres
APP_JDBC_PERSISTENCE_ENABLED=true
```

后端启动时会自动执行：

```text
src/main/resources/sql/maintenance_schema.sql
src/main/resources/sql/maintenance_seed.sql
```

PgVector 向量检索仍是独立能力。需要真实向量知识库时，再打开 `app.vectorstore.pgvector.enabled` 并确保 PostgreSQL 已安装 pgvector 扩展。

## 答辩演示流程

1. 打开首页，说明系统覆盖检修业务闭环。
2. 进入设备检修中台，展示态势看板。
3. 查看设备台账，选择严重风险的电机。
4. 打开案例知识库，说明故障知识沉淀方式。
5. 打开图片分析，输入“焦痕、变色、绝缘破损”等描述，获得图片特征和相似案例。
6. 打开多模态诊断，输入温度、振动、电流和图片特征，生成风险等级和证据链。
7. 查看自动生成的检修作业单，并演示状态流转。
8. 导出诊断报告，完成闭环。
