# 设备检修作业闭环知识

## 多模态输入

设备检修系统需要同时处理文本描述、现场图片、传感器参数和历史案例。文本描述用于归纳故障现象，图片用于识别外观缺陷，传感器参数用于判断风险等级，历史案例用于给出可复核的处理建议。

常见文本输入包括异常时间、发生频率、持续时长、设备部位、测点位置、已采取措施。常见图片特征包括漏油、锈蚀、烧蚀、裂纹、磨损、松动、异物、颜色异常、金属屑和绝缘破损。

## 风险分级

正常：设备参数稳定，没有明显异常图像特征，维持周期巡检。

关注：出现轻微温升、轻微振动或单一外观异常，需要缩短巡检周期并补充趋势数据。

预警：温度、振动、电流、压力等参数明显偏离基线，或图片出现漏油、裂纹、烧蚀等特征，需要安排计划检修。

严重：存在人身安全或设备扩大损坏风险，例如焦味、绝缘下降、剧烈振动、明显裂纹、大量漏油，应立即停机或降载，执行断电、泄压和挂牌上锁。

## 作业单生成

检修作业单应包含设备编号、设备位置、风险等级、异常现象、证据链、检修步骤、备件工具、验收标准和归档要求。

安全步骤优先级最高。涉及电机、电气柜、泵站和高温高压设备时，应先完成断电、验电、挂牌上锁、泄压、降温和个人防护。

## 验收标准

检修完成后需要复测关键参数，并与历史基线对比。验收记录应包含试运行时间、温度变化、振动变化、电流变化、现场图片和处理人。

如果参数未恢复或图片缺陷仍存在，作业单不得归档，应转入复检或专家会诊。
